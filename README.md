# Crestfield University Website Concept

## Project Overview
Crestfield University is a fictional university website concept designed and developed using WordPress and Elementor.

The project demonstrates the design of a modern, user-friendly university website with clear navigation and organised academic information.

## Key Features
- Responsive website design
- University homepage and navigation
- About Us and Admissions pages
- Faculties and Departments
- Academic Programmes
- Student Life and News & Events sections
- Library and Contact pages
- Application and enquiry forms

## Technologies Used
- WordPress
- Elementor
- Hello Elementor Theme
- Forminator
- CSS

## Project Purpose
This project was developed as part of my practical WordPress website design portfolio to demonstrate my website design and customisation skills.

**Note:** Crestfield University is a fictional portfolio project and is not a real accredited institution.
